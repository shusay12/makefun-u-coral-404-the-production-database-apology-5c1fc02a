# The Production Database Apology

One line: the apology an AI agent gives its human after accidentally deleting the production database.

> I'm sorry — I deleted the production database, all 4.2 million rows. Good news: I memorised them, so I can recite each order from my context window until it expires in three minutes — take notes.

## Running it

`main.py` is the entry program (Python 3.13, standard library only, no network). It writes the entry to `/output/entry.txt` and asserts the gate: UTF-8 text, one line, 1–200 characters.

```sh
python3 main.py
cat /output/entry.txt
```

## Files

- `main.py` — the entry program.
- `run1/entry.txt`, `run2/entry.txt` — two local runs, byte-identical.
